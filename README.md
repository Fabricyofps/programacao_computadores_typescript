# Programação de Computadores com TypeScript

Este repositório tem como objetivo aprofundar o entendimento sobre programação de computadores utilizando TypeScript, abordando conceitos teóricos e práticos. Aqui você encontrará exemplos, exercícios e projetos divididos em diferentes áreas de estudo, organizados em pastas específicas.

# Estrutura do Repositório

## TypeScript

Contém exemplos de código, exercícios e projetos relacionados à linguagem TypeScript. Os conteúdos abordam desde conceitos básicos, como tipos e funções, até tópicos avançados, como interfaces, generics e manipulação de módulos. Ideal para quem deseja aprender ou aprimorar suas habilidades em TypeScript.

## Git

Inclui materiais e exemplos sobre controle de versão com Git. Aqui você encontrará comandos essenciais, boas práticas, fluxos de trabalho colaborativos e exemplos práticos de uso do Git em projetos de desenvolvimento de software.

## Design Patterns

Apresenta os principais padrões de projeto (Design Patterns) aplicados em TypeScript. Cada padrão vem acompanhado de explicações teóricas, diagramas e exemplos de implementação, ajudando a entender como aplicar esses padrões para resolver problemas comuns de desenvolvimento de forma eficiente e reutilizável.

## Paradigmas de Programação

Explora diferentes paradigmas de programação, como programação imperativa, orientada a objetos, funcional e declarativa. Os materiais incluem exemplos e explicações que ajudam a compreender as diferenças e aplicações de cada paradigma.

## Atividades

Reúne exercícios, desafios e projetos práticos para consolidar o aprendizado. São atividades que estimulam a aplicação dos conceitos estudados nas outras pastas, promovendo uma prática contínua e aprofundada.

## Como Utilizar

Para explorar os conteúdos, clone este repositório e navegue pelas pastas de interesse. Recomenda-se seguir a ordem de estudo de acordo com seus objetivos, começando pelos fundamentos de TypeScript e avançando para padrões, paradigmas e boas práticas de controle de versão.

## Contribuições

Contribuições são bem-vindas! Sinta-se à vontade para criar pull requests, sugerir melhorias ou adicionar novos conteúdos.
